Collega Conti a GitHub

Serve una chiave di accesso al solo repository Frankdinapoli/Conti. Resta solo su questo telefono; i movimenti non vengono salvati qui.

  1. Apri github.com → foto profilo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token (anche dal Mac: poi copia sul Mac e incolla qui con gli Appunti condivisi; non mandarlo via chat o email).
  2. Nome: Conti iPhone · Scadenza: 1 anno · Repository access: Only select repositories → Conti.
  3. Permissions → Repository permissions → Contents: Read and write per registrare contanti e correggere categorie, oppure Read-only per guardare soltanto. Nient'altro.
  4. Generate token, copialo e incollalo qui sotto.

Usa un token diverso da quello del Mac: se perdi il telefono lo revochi da GitHub senza toccare il Mac.
